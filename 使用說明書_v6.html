套件安裝指令

# 必裝套件
pip install python-telegram-bot==20.x nest_asyncio numpy pandas yfinance
pip install scipy scikit-learn aiosqlite

# 強烈建議安裝（啟用進階功能）

⚙️ 二、設定 Bot Token

向 @BotFather 申請 Token 在 Telegram 搜尋 @BotFather，輸入 /newbot，依指示命名，取得 Token（格式：1234567890:AAF_xxxxx）。
填入程式碼 開啟 main.py，找到以下行並替換： 
TOKEN = "你的Token"   # ← 替換這裡
（建議）用環境變數更安全 
import os
TOKEN = os.environ.get("TG_TOKEN", "")  # 設定環境變數 TG_TOKEN

第一階段：粗篩（Coarse Filter）

  • 下載近 5 日 OHLCV 資料
  • 過濾：日均量 < 1,000,000 股（1000張）的標的直接淘汰
  • 依掃描模式選取候選：量能異常、回調、下跌、趨勢突破等
  • 批次大小：300 檔，批次間 sleep 1 秒

第二階段：精篩（Fine Analysis）

  • 下載 1 年完整 OHLCV 資料（需至少 60 個交易日）
  • 在 Worker Process（第2個核心）執行 v6 全模型計算
  • 包含：DBN、卡爾曼、EVT、GMM、HMM、流動性評估等
  • 批次大小：50 檔，批次間 sleep 2 秒

📂 六、掃描分類說明

📈 強勢股（explosive）

條件：估算成交量 > 均量×2 且今日收盤 > 開盤

策略：追買強勢突破，配合量能確認

適合：短線動能交易，1~5日持有

🦄 黑馬股（dark_horse）

條件：估算成交量 < 均量×0.8（低調量縮）

策略：潛伏蓄勢，等待量能爆發

適合：中線布局，等待觸發點

🔻 回調（pullback）

條件：今日收盤 < 昨日收盤，但均線仍多頭

策略：強勢回調中的買點

適合：趨勢交易者，逢回加碼

🔄 止跌（reversal）

條件：近5日跌幅 > 3% + 多項底部訊號

策略：技術底部，等待反彈觸發

適合：逆勢交易，需嚴格停損

📉 今跌看好（intraday_dip）NEW

條件：今日下跌 + EMA5 > EMA20（短線仍多）+ DBN評分 > 1.0

策略：短線修正即買點，結構未破壞

適合：當日或隔日反彈交易

💚 長線看好（long_term）NEW

條件：EMA20 > EMA60 > EMA120 + 近3月漲幅 > 10% + Hurst > 0.55 + Alpha > 0 + Sortino > 0.3

策略：長期持有，看長線趨勢

適合：長線投資者，不在意短線波動

📊 七、DBN 評分系統

評分公式

後驗多頭機率 = 貝氏更新(先驗機率, 所有觸發訊號) 評分 = (後驗多頭機率 - 0.5) × 10 ∈ [-5, +5] 體制先驗：多頭=0.60 | 盤整=0.50 | 震盪=0.48 | 空頭=0.40

DBN 共線性處理（[v6-A]）

RSI 與 KD 高度相關，若直接連乘會導致機率膨脹。DBN 將訊號分組：

  • 動能組：RSI、KD、自適應RSI、KD超賣金叉 → 只取似然比最大的代表
  • 趨勢組：KAMA、卡爾曼、MACD、自適應MACD、多週期共振 → 同組懲罰
  • 量能組：爆量突破、訂單流強勢、訂單流失衡 → 只取代表

評分門檻（依體制動態調整）

體制門檻說明
🟢 多頭（bull）2.0市場強勢，標準放寬
🟡 盤整（normal）2.5正常標準
🟠 震盪（high_vol）3.5波動大，提高門檻
🔴 空頭（bear）4.0空頭市場，極嚴格

信心度等級

  • 🟢 高（high）：|後驗 - 0.5| > 0.25（後驗 > 75% 或 < 25%）
  • 🟡 中（medium）：|後驗 - 0.5| > 0.12
  • 🔴 低（low）：後驗接近 0.5，訊號混沌

紅綠燈調度機制

系統使用 TrafficLightScheduler 確保資源分配：

  • 🔴 紅燈（/check）：最高優先級，立即暫停背景掃描，分析完成後釋放
  • 🟡 黃燈（/buy）：純讀 SQLite WAL，秒回，不影響其他操作
  • 🟢 綠燈（背景掃描）：低優先級，批次間主動 sleep，隨時可被中斷

雙核心分工

核心 1：asyncio Event Loop

  • yfinance 批次下載（非同步 I/O）
  • Telegram 訊息收發
  • SQLite WAL 讀寫
  • 調度器 green_checkpoint

核心 2：Worker Process（spawn）

  • v6 全模型計算（CPU 密集）
  • DBN/HMM/Kalman/EVT/GMM
  • Numba JIT 加速數值計算
  • 完全不阻塞主 Event Loop

SQLite WAL 快取架構

  • WAL 模式：讀寫不互鎖（讀快取同時可以寫新資料）
  • 128 MB Cache + 256 MB mmap：降低 I/O 瓶頸
  • 每5輪自動 VACUUM（縮減 DB 大小）
  • 快取 TTL：24小時（DB_EXPIRE_SEC = 86400）

🧠 十、v6.0 新增模型

[v6-A] 動態貝氏網路（DBN）

DAG 層級共線性懲罰：將 RSI+KD 等高相關訊號分組，每組只取最強代表進行貝氏更新，避免機率膨脹。

dedup: 同組訊號 → max(|P-0.5|) 的代表
penalty: 0.8^(overlap-1)

[v6-B] 隱馬爾可夫模型（HMM）

3狀態 Gaussian HMM 辨識市場體制：Bull / Normal / Bear。依報酬率均值排序狀態，融合 EMA 雙重確認。

需安裝 hmmlearn，否則退回 EMA 方法

[v6-C] 卡爾曼濾波（Kalman）

動態去噪趨勢：狀態向量 [price, velocity]，比 EMA 反應更快。無需 filterpy，有純 numpy 降級版本。

F=[[1,1],[0,1]] H=[1,0]
x_k = F·x_{k-1} + K·(z-H·x_pred)

[v6-D] 極值理論（EVT/GPD）

廣義帕雷托分佈擬合報酬率尾部，比常態分佈更準確估計極端事件機率。用於超跌反彈概率計算。

P(X>u+y) ≈ (n_u/n)·[1+ξy/σ]^(-1/ξ)

[v6-E] 自適應週期（FFT+Hilbert）

FFT 找出去趨勢後的主導週期，動態調整 RSI/MACD 的參數 n（週期範圍：5~40日）。

dominant_cycle = argmax|FFT(detrended)|
inst_freq = Δphase / (2π)

[v6-F] 高斯混合模型（GMM）

成交量加權 GMM 找出主要價格聚集區（支撐/壓力），給出每個成分的中心值與強度（混合比例）。

p(x) = Σ_k π_k · N(x; μ_k, Σ_k)
POC = argmax(π_k)

[v6-G] 跳空缺口分類

依整合程度、成交量比、RSI 位置自動分類：突破缺口（看多）/ 逃逸缺口（延續）/ 竭盡缺口（警示）。

[v6-H] Alpha/Beta 計算

OLS 回歸個股報酬對大盤報酬，計算年化 Alpha（超額報酬）與 Beta（系統性風險）。

r_stock = α + β·r_mkt + ε
Alpha_年化 = intercept × 252

[v6-I] 量價背離量化

Price ROC vs Volume ROC 的滾動相關係數，量化量價背離程度：健康突破 / 量縮止跌 / 量縮價漲（弱化）。

[v6-J] 自適應移動停利

Chandelier Exit 基礎，隨持倉天數與獲利幅度動態縮減 k 值，保護短線利潤。

k = 3.0 - days×0.05 - profit%×0.1
stop = max(H22) - k × ATR14

[v6-K] 流動性評估

Amihud 非流動性指標 + 滑價估計，過濾日均量過低的假突破訊號。

Amihud = |R| / Volume × 10^6
slippage = spread × vol_ratio

[v6-L/M/N] 其他機制

  • L 風險平價：協方差矩陣等風險貢獻
  • M 時間停損：超過N日未發動自動降分
  • N 大盤熔斷：廣度<20%封鎖突破策略

❓ 十一、常見問題 FAQ

Q：大盤顯示「極凍 0%」但市場明明很好？

A：這是初始化問題。啟動後 global_market_status 的 total=0，需等待背景掃描的大盤廣度計算完成（第一輪掃描後約更新）。請輸入 /update 啟動背景掃描並等候，或使用 /breadth 查看診斷。

Q：Worker v6 計算錯誤 "only 0-dimensional arrays can be converted"？

A：需更新 _safe_float 函數，加入 numpy 0-d array 處理：
if hasattr(val, 'item'): val = val.item()

Q：掃描很慢，要怎麼加速？

A：① 安裝 numba 啟用 JIT 加速；② 安裝 hmmlearn 和 filterpy；③ 確認 GCP 節點選台灣/亞洲。正常情況全台 1800 檔約 20 分鐘。

Q：/export 匯出失敗？

A：需安裝 openpyxl（pip install openpyxl）。若仍失敗，系統會自動降級為 CSV 格式。

Q：twstock 找不到某些代號？

A：twstock 資料庫可能未包含新上市股票。可直接用股票代號（純數字）輸入，Bot 會嘗試用 yfinance 解析。

Q：/check 顯示「找不到 xxx」？

A：① 確認是否安裝 twstock；② 嘗試改用純數字代號；③ 若是上櫃股票可能需手動加 .TWO。

Q：如何控制掃描最低成交量門檻？

A：修改程式碼第 117 行：MIN_VOL_DAILY = 1_000_000（目前設為 100萬股即 1000張）。
